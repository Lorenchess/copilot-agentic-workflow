RSTACK Mission Control: the Live view

The Live screen for a run whose Developer was just dispatched, as built in PR #5. Below it are the three other moments that matter most.

A fixed-width illustration, not the build. Where they differ, the code in rstack-sdlc/dashboard/web/ and the demo replay (node scripts/dashboard-demo.ts --no-screenshots --replay) are authoritative.
  • Motion here is a preview. The hand-off packet, card pop, feed slide-in and finish sweep repeat every 6 s so they can be seen. In the product each plays once, when a journal event is committed. The Live dot beats here every 4 s; in the product it beats once per real server heartbeat.
  • The only real loops are the calm glow around the current card and the agent tile while a dispatch awaits its result, and the amber pulse while a human is needed. A blocked or finished run is still.
  • Not shown here:
    • the light theme
    • the Inspect view (timeline, attempts, tests, audits, reviews, evidence, problems)
    • the landing page with run tiles
    • full screen
    • the responsive layout: 7, then 5 cards per row, then a vertical list
