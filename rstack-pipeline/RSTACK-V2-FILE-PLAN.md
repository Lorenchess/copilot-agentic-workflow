## 1. Meaning of the actions

- **KEEP:** preserve purpose and path; any proposed shortening is explicitly stated.
- **SIMPLIFY / CONSOLIDATE:** remove duplicated specification only after its canonical owner and every consumer are updated.
- **ARCHIVE authority:** remove a historical file from current normative precedence through an explicit forward supersession map. Keep its original bytes, path and dated review history. This is not a file move or deletion.
- **NEW, conditional:** add only after the owner chooses an enforced runtime profile and approves exact code scope.
- **Reduction:** qualitative maintenance/context expectation. Character counts are measured source sizes, not host token savings or promised reductions.
